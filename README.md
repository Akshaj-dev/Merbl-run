# Multi-Path Marble Run

## Project Overview

My project is a 3D-designed marble run created in Onshape. It features multiple routes for marbles to travel along, creating different paths and making the run more enjoyable to use with friends and family.

I also designed detachable accessories, including a cupholder and an umbrella, to improve the functionality and appearance of the project.

## Features

- Multiple routes for marbles to follow.
- Smooth track sections designed to guide marbles.
- Detachable cupholder accessory.
- Detachable umbrella accessory.
- 3D CAD design created using Onshape.
- Modular components that can be assembled and adjusted.

## 3D Printing Instructions

1. Open the supplied STL files in a slicer such as Ultimaker Cura or PrusaSlicer.
2. Check that each part is correctly oriented on the build plate.
3. Select PLA filament and a suitable profile for the printer being used.
4. Use a 0.2 mm layer height as a starting point.
5. Use approximately 15–20% infill as a starting point for structural parts.
6. Preview every layer and check whether supports are needed beneath overhangs.
7. Slice the model and review the estimated filament usage and printing time.
8. Print the components and allow them to cool before removing them.
9. Check each part for rough edges, weak sections or printing defects before assembly.

These settings are starting recommendations. The final settings should be adjusted to suit the printer, geometry and slicer preview.

## Assembly Instructions

1. Lay out all the printed components and identify the matching track sections and supports.
2. Assemble the main supports on a stable, level surface.
3. Attach the track sections in the intended order, ensuring that the joins are aligned.
4. Check that each route has a continuous path and that the marbles can pass through without becoming trapped.
5. Attach the cupholder to its designed mounting point.
6. Attach the umbrella accessory to its mounting point.
7. Check that detachable accessories fit securely and can be removed without damaging the printed parts.
8. Test the run with one marble at a time.
9. Adjust loose connections or misaligned sections before using multiple routes.

The exact joining method depends on the final CAD design. Do not force components together if their dimensions do not match.

## Testing

The completed marble run should be tested on a level surface. Each route should be checked individually to confirm that marbles travel through it smoothly. The supports should remain stable, and detachable accessories should remain secure during normal use.
