# Merbl-run

## Project Overview
Merbl-run is a 3D-designed marble run created to provide an enjoyable and interactive experience. The design features a spiral track, curved tubes and supporting structures that guide the marble through the model.

## Features
- **Spiral marble track:** Guides the marble through a series of curved loops.
- **Detachable cup holder:** Adds extra functionality to the design.
- **Detachable umbrella:** Improves the appearance and style of the product.
- **Compact structure:** Uses a base and supporting pillars to hold the different components together.

## How It Works
The marble travels through the track using gravity, moving along the spiral and curved sections. The detachable accessories can be removed when they are not needed.

## Design Development
The original concept was developed into a more detailed 3D model. Additional features, including a detachable cup holder and umbrella, were introduced to improve the design's appearance and versatility.
